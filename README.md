## Files

- `script.js` — interactions

## Run locally
Open `index.html` in a browser.

## Deploy to Netlify
1. Go to Netlify.
2. Choose **Add new site → Deploy manually**.
3. Drag the `arul-raj-portfolio` folder into the deploy area.
4. Your portfolio will be live on a Netlify subdomain.
